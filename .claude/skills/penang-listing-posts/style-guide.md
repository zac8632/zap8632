# Visual style guide — cover creatives

Derived from the user's reference samples (Nexus Tech Park, Address 17,
Dubai villa, Tilal Al Ghaf). Goal: **bright, clean, premium**. Lots of breathing
room, thin elegant dividers, restrained palette, one clear hero image.

## Canvas sizes
- **4:5 portrait — 1080 × 1350 px** (primary: Instagram / Threads feed)
- **9:16 vertical — 1080 × 1920 px** (Instagram Story / TikTok / WhatsApp status)
- Design the 4:5 first; the 9:16 is the same system with more vertical air.
- Keep all text/logos inside a safe margin (≈ 80 px on 1080-wide) and, for 9:16,
  clear of the top ~250 px and bottom ~320 px (platform UI overlap).

## Layout system (cover slide)
Top → bottom zones:

1. **Top bar** — no logo / no business name (by choice). Optional: a small,
   tasteful area tag top-right (e.g. "TANJUNG BUNGAH") in gold small-caps. Keep
   it minimal — the property is the hero.
2. **Headline block** — a bold uppercase sans line + one elegant script/serif
   accent word (e.g. "HOMES THAT **INSPIRE** / *Better Living*"). Short. Never
   states a fact that isn't in the listing. Optional small **"JUST LISTED"**
   badge (gold pill, top area) for new-listing posts.
3. **Stat chip row** — the key info band. Evenly spaced, separated by thin
   vertical dividers, each with a small line icon:
   - `PRICE` — MYR primary, large; USD/SGD approx smaller beneath.
   - `BEDS` / `BATHS` — only if known.
   - `SIZE` — sqft, only if known.
   - `TENURE` — only if known.
   Omit any chip whose data is blank (never show an empty or guessed chip).
4. **Hero image** — the property, large, occupying the lower ~55–65%. Use the
   listing's best real photo. Gradient scrim behind text for legibility.
5. **Footer** — a soft CTA line only (e.g. "DM to arrange a viewing"). NO phone,
   WhatsApp, link, or handle — ever (privacy + shadowban safety). Small, centred.

## Colour & finish — "Coastal Luxe"
- Background: White `#FFFFFF` / Soft Mist `#F2F6FA` (bright, airy base).
- Primary: Azure → Ocean gradient `#1CA9E0` → `#0E6BA8` (used in scrims / bands).
- Deep contrast: Midnight Navy `#0A2540` for headline text on light, or as a
  photo scrim with white text.
- Accent: Champagne Gold `#D4AF37` for dividers, icons, and the script word.
- Keep high contrast and legibility. Subtle depth only (soft shadow, thin 1px
  gold dividers). No heavy borders, no clutter, max 2 type styles.

## Typography
- Headline / stats / labels: **Montserrat**, bold / extra-bold, uppercase;
  labels in small-caps, tracking-wide.
- Accent word: **Playfair Display** italic (or Great Vibes for a scriptier look).
- Both are free Google Fonts — safe to bundle in the render pipeline.

## Carousel structure (the full post)
1. **Cover creative** (this style guide).
2. **Real listing photos** — the owner's actual photos, optional one-line caption
   strip (no logo, no contact). Enhanced only per the image rules; never
   fabricated.
3. **CTA slide** — clean closing card: a short soft line only ("Enquire now" /
   "DM to arrange a viewing"). NO number, link, or handle.
- Max 10 slides for Instagram. If more photos exist, pick the strongest.

## Do / don't
- DO keep it airy, consistent, and legible on a phone at a glance.
- DO let the real hero photo carry the slide.
- DON'T overlay fake amenity labels or specs not in the listing.
- DON'T over-process photos into something that misrepresents the unit.
- DON'T crowd the stat row — 3–4 chips max reads best.
