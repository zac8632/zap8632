- **Instagram**: 8–15 total, mix of sets above. Put at caption end or first comment.
- **TikTok**: 3–6 max, include `#PenangProperty` + area + `#fyp`.
- **Threads**: 0–1.
- **WhatsApp status**: none.
- Only use area tags that genuinely match the listing (don't tag `#Gurney` on a
  Tanjung Bungah unit).
- Periodically check none of these have become banned/flagged; prune if so.
