# Mandarin Terms — Malaysian-Chinese Property Glossary

MEI reads this file before every `--lang zh` or `--lang bilingual` generation. Edit freely — add phrases you use, delete ones you don't.

## Malaysian-Chinese-specific vocabulary (use THESE, not mainland versions)

| Concept | Use this ✅ | Avoid this ❌ |
|---|---|---|
| House | 屋子 (uk-chù) | 房子 (fángzi, mainland) |
| Property | 产业 (chǎnyè) | 房地产 (fángdìchǎn, formal) |
| Down payment | 头期 (tóuqī) | 首付 (shǒufù, mainland) |
| Currency | 令吉 / RM / 块 | 元 (yuán, mainland) |
| Mortgage | 房贷 or "loan" | Very formal 按揭 |
| Unit | 单位 (dānwèi) | 户 (hù) |
| Developer | 发展商 (fāzhǎnshāng) | 开发商 (kāifāshāng, mainland) |
| Show unit | 样品屋 (yàngpǐn wū) | 样板房 (yàngbǎnfáng, mainland) |
| Handover / VP | 交屋 (jiāo uk-chù) | 交房 (jiāo fáng, mainland) |
| Sub-sale | 二手 (èrshǒu) | Same |

## Native Mandarin hook types (10)

1. 数字型 Number — "3个错误..."
2. 反常识型 Counter-intuitive — "你以为... 其实..."
3. 警告型 Warning — "千万别..."
4. 问题型 Question — "买新盘, 你真的看得懂吗?"
5. 场景型 Scene — "昨天带客户看盘..."
6. 悬念型 Cliffhanger — "看完你就懂..."
7. 承诺型 Promise — "看完帮你省20万"
8. 权威型 Authority — "做房产X年, 告诉你..."
9. 干货型 Pure-value — "满满干货!"
10. 收藏型 Save-bait — "建议收藏!"

## Native Mandarin content structures (5)

| Structure | Flow | Best for |
|---|---|---|
| 痛点公式 (Pain) | 痛点 → 共鸣 → 揭秘 → 方法 → 收藏 | Objection posts |
| 反转公式 (Twist) | 常见做法 → "但是..." → 真相 → 正确做法 | Contrarian posts |
| 故事公式 (Story) | 场景 → 转折 → 结果 → 感悟 → 建议 | Personal stories |
| 教学公式 (Teaching) | 问题 → 3步方法 → 案例 → 总结 | How-to content |
| 对比公式 (Compare) | 选项A → 选项B → 3维度对比 → 结论 | Project comparisons |

## Malaysian-Chinese tone rules

- Casual, not formal
- Mix English tech terms (developer names, SPA, VP, DIBS, MRT) freely
- Use more emojis than mainland content ✨🏠💰
- Cantonese/Hokkien flavor OK in speech content, less in written
- Short sentences work better than long ones (mobile reading)
