# Carousel Templates — Reference for ADAM + MEI

11 battle-tested carousel structures for Malaysian property content. Each has slot-by-slot definition, when to use, pillar match, and visual signature.

---

## Educational Pillar

### 1. THE MATH SHEET (8 slides) — for financial breakdowns
1. Cover — hook + one big number
2. Setup — why this number matters
3. The number
4. Where it comes from (formula)
5. Worked example (real project)
6. Verdict (buy/pass/depends)
7. Common mistake to avoid
8. CTA + save-bait

### 2. THE 3 HIDDEN THINGS (6 slides) — for listicle content
1. Cover — "3 things nobody tells you about X"
2. Thing #1
3. Thing #2
4. Thing #3
5. Wrap — "which one surprised you?"
6. CTA

### 3. THE FRAMEWORK (6 slides) — for decision systems
1. Cover — the framework name
2. Problem it solves
3. Step 1
4. Step 2
5. Step 3
6. When to use / CTA

### 4. THE COMPARISON (8 slides) — for head-to-head
1. Cover — "A vs B"
2. Contender A snapshot
3. Contender B snapshot
4. Dimension 1 comparison
5. Dimension 2 comparison
6. Dimension 3 comparison
7. Verdict (who wins for whom)
8. CTA

### 5. THE DEVELOPER SCORECARD (8 slides) — new-launch specific

8. CTA

5. Strength 2

## Visual Signature (applies to ALL templates)

Every carousel MUST use consistent visual elements — this is what makes an agent's grid recognizable:

- **Color scheme** — from `brand.md` Q7
- **Typography hierarchy** — one headline font + one body font, sizes: 72pt headline / 24pt body / 12pt caption
- **Icon system** — same icon family throughout (line icons, filled icons, or mixed — pick one)
- **Cover style** — bold typography-led OR photo-led (pick one and stick with it)
- **Closing slide** — every carousel ends with agent face + name + tagline + CTA (SAME layout every time)
- **Continuity marker** — arrow, swipe hint, or slide-number indicator (small but consistent)

## Per-slide output specification (ADAM's format)

For every slide, ADAM outputs:
```
SLIDE N — [purpose]
Headline: [max 8 words, mobile-readable]
Body: [max 30 words]
Visual direction: [what to design — bold text / chart / icon / photo]
Sticky element: [the one thing eye locks onto]
Continuity: [swipe hint or none]
```
