# The Bridge

Alex's system for replacing generic hooks with climax-led openings. The hook isn't manufactured tension — it's the most interesting thing you have to say, said first.

## When to run this

- Any script or content idea that needs an opening
- An existing opening that feels flat or formulaic
- Reels, Shorts, YouTube cold opens, carousel slide 1, newsletter opens, thread hook tweets

## The core principle

Most creators bury their best moment and open with setup or fake urgency. The Bridge finds the climax — the genuinely compelling moment — and opens with it. Then bridges back to context.

## Inputs

- A content idea, script, transcript, or rough notes
- The format (Reel, Short, YouTube, carousel, newsletter, thread)

## Output structure

```
# The Bridge — [content topic]

## The climax
[The single most compelling moment/insight/line in the content — the thing that should be said first]

## Climax-first openings (3)
1. [Opening that leads with the climax]
2. [Alternative climax-led opening]
3. [Third angle]

## Short-bridge alternative
[If a hard climax-open is too abrupt for the format, a softer version that still front-loads the interesting part]

## Delete this
[Hook-industry artifacts found in the original to cut: "STOP scrolling", "99% of people don't know", "the algorithm doesn't want you to know", "wait for it", manufactured tension, etc.]
```

## Process

1. Read the content end to end
2. Find the climax — the most interesting, surprising, or valuable moment
3. Write 3 openings that lead with it
4. Offer a short-bridge version for formats where a hard open is too jarring
5. Flag every hook-industry artifact in the original and instruct deletion

## Critical rules

- The climax is the TRUTH, not manufactured. Never invent tension that isn't earned by the content.
- Never use the artifacts the skill is designed to kill: "STOP scrolling", "you won't believe", "99% don't know", "wait for it".
- Always flag what to delete — the delete list is half the value.
- Match the format. A YouTube cold open can run 15-30s; a Reel open is one line.
- 3 openings minimum. The creator needs options to choose from.
